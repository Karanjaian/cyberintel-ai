# CyberIntel AI

Open-source cybersecurity intelligence platform that collects, analyzes, enriches, and distributes actionable cyber threat intelligence using local AI models.

## Features

* RSS News Aggregation
* Cybersecurity Threat Intelligence
* CVE Tracking
* AI Summarization
* Duplicate Detection
* Threat Scoring
* Telegram Alerts
* REST API
* Dashboard
